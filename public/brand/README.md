# Guild's Bounty artwork

The header shows one picture: `GuildsBounty-Both.png`, the whole lockup - the chest, the
name and *Shared items across your guilds* - in a single file. The top bar sets its width
(180 CSS pixels) and grows to the height that follows, so the picture is never stretched.

- `GuildsBounty-Both.png`: chest, name and the line under it, 1752 × 897; displayed 180 CSS
  pixels wide in the header.
- `GuildsBountyLogo.png`: the same plaque without the name or the line, 580 × 573; a square
  picture for a spot that has no room for lettering.
- `logo.png`: the earlier combined logo, 480 × 90; suitable for display at 240 × 45.
- `mark.png` and `wordmark.png`: the older two-piece brand - the people and gift, 152 × 91,
  and the name on its own, 320 × 59. The header no longer draws them, because the plaque
  already carries both.

Keep each image's aspect ratio when resizing. The PNG lettering does not depend on fonts
installed on the visitor's device.
